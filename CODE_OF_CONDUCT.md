# Code of Conduct

Aria Builder is an open source project for people building serious web software
together. We want participation to be direct, kind, and useful.

## Expected Behavior

- Be respectful of other contributors' time, context, and experience level.
- Give technical feedback without personal attacks.
- Assume good intent, then ask clarifying questions when something is unclear.
- Keep discussions focused on the work.
- Credit ideas, reports, and contributions generously.
- Accept maintainer decisions when a thread has reached a decision.

## Unacceptable Behavior

- Harassment, threats, intimidation, or sustained personal attacks.
- Discriminatory language or behavior.
- Sexualized comments or unwelcome attention.
- Publishing private information without permission.
- Trolling, insulting, or derailing project spaces.
- Repeatedly pushing a decision after maintainers have closed the discussion.

## Scope

This code of conduct applies in project spaces, including GitHub issues, pull
requests, discussions, security reports, community chat, events, and any other
space where someone is representing the Aria project.

## Enforcement

Maintainers may remove comments, close threads, reject contributions, block
users, or take other action needed to keep the project healthy.

If you experience or observe unacceptable behavior, contact the maintainers
privately at `conduct@ariabuilder.io`. Include relevant links, screenshots, and
context where possible.

Reports will be handled with discretion. Retaliation against someone who makes
a good-faith report is not acceptable.
